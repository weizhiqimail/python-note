+ 封装： 将 抽象 得到 的 数据 和 行为（ 或 功能） 相结合， 形成 一个 有机 的 整体（ 即 类）； 封装 的 目的 是 增强 安全性 和 简化 编程， 使用者 不必 了解 具体 的 实现 细节， 而 只要 通过 外部 接口、 特定 的 访问 权限 来 使用 类 的 成员。

# 3. [isinstance 和 type](../code/06-isinstance_type.py)
+ `is` 和 `==` 不一样，is 是用来判断两个对象的 id 是否相同，也就是内存地址， == 用来判断两个变量的值是否相等

```python
a = 100
b = 10 ** 3
print(a == b) # True
print(a is b) # False
```

> 因为出于对性能的考虑，Python内部做了很多的优化工作，对于整数对象，Python把一些频繁使用的整数对象缓存起来，保存到一个叫small_ints的链表中，在Python的整个生命周期内，任何需要引用这些整数对象的地方，都不再重新创建新的对象，而是直接引用缓存中的对象。Python把这些可能频繁使用的整数对象规定在范围 `[-5, 256]` 之间的小对象放在small_ints中，但凡是需要用些小整数时，就从这里面取，不再去临时创建新的对象。

# 4. [类变量和实例变量](../code/07-class_instance_var.py)
+ 类中的 self 代表是的实例，而不是类自身
+ 如果在实例中寻找某个属性，首先会去自身查找，如果实例有这个属性，那么就直接获取。
+ 如果实例没有这个属性，那么就会直接去类中的 `__init__` 中去找，找到就直接使用。
+ 如果类的 `__init__` 中没有，那么就去类的数属性中去查找。
+ 如果类的属性中也没有，那么就去类的父类去找，再按照类的 `__init__` 和类的属性的属性去查找。
+ 实例可以修改自己的变量，但是不可以修改类的变量，包括父类。类可以修改自己的变量，但是不可以修改实例的变量。也就是说，实例和类只能修改自身的变量，不能修改别人的变量。

## 4.2 C3 算法

+ 多继承

```python
class D:
    pass


class B(D):
    pass


class E:
    pass


class C(E):
    pass


class A(B, C):
    pass


print(A.__mro__)

# (<class '__main__.A'>, <class '__main__.B'>, <class '__main__.D'>, <class '__main__.C'>, <class '__main__.E'>, <class 'object'>)
```

+ 菱形继承关系
```python
class D:
    pass


class B(D):
    pass


class C(D):
    pass


class A(B, C):
    pass


print(A.__mro__)
# (<class '__main__.A'>, <class '__main__.B'>, <class '__main__.C'>, <class '__main__.D'>, <class 'object'>)
```

# 12. `__new__` 和 `__init__`
+ `__new__` 负责对象的创建，在创建对象时调用，会返回当前对象的一个实例。如果返回的不是当前对象，而是其他的对象，那么 init 实例化的就是其他的对象，而不是当前的对象。
+ `__init__` 负责对象的初始化，创建对象后调用，对当前对象的一些实例初始化，无返回值
+ 如果 `__new__` 没有正确返回当前类 cls 的实例，那么 `__init__` 是不会被调用的，即使是父类的实例也不行
+ 结论
    + 继承自 object 的新式类才有 `__new__`
    + `__new__` 至少要有一个参数 cls， 代表要实例化的类，此参数在实例化时由 Python 解释器自动提供，`__new__` 必须要有返回值，返回实例化出来的实例，可以 return 父类 `__new__`出来的实例，或者直接是 object 的 `__new__` 出来的实例
    + `__init__` 有一个参数 self，这就是 `__new__` 返回的实例，`__init__` 在 `__new__` 的基础上可以完成其他初始化的操作，`__init__` 不需要返回值
    + 如果 `__new__` 返回一个对象的实例，那么会隐式调用 `__init__`

```python
# 这种情况下 __new__ 返回了当前类 cls 的实例，可以正常调用 __init__
class ClsTest(object):
    def __new__(cls, *args, **kwargs):
        print('new')
        return object.__new__(cls, *args, **kwargs)
    
    def __init__(self):
        print('init')


c = ClsTest()
```

+ `__new__` 没有正确返回当前类 cls 的实例

```python
class ParentClsTest():
    pass


class ClsTest():

    def __new__(cls, *args, **kwargs):
        print('new')
        return object.__new__(ParentClsTest, *args, **kwargs)

    def __init__(self):
        print('init')


c = ClsTest()
```
