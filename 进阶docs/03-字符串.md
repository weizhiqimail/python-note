## 1. 拆分字符串
+ 问题：要把某个字符串依据分隔符号拆分不同的字段，该字符串包含多种不同的分隔符
+ 例如 s = 'ab;dksdswe2,;[]\/*-+!@#$%^&*()_+kejsklfjkdsjfs'
+ 其中, ; | \t都是分隔符号，该如何处理
+ 解决：使用正则表达式的re.split()方法，一次性拆分字符串

```python
import re

s = 'ab;dksdswe2,;[]\/*-+!@#$%^&*()_+kejsklfjkdsjfs'

r = re.split(r'[,;|\t]+', s)
print(r)
```

+ 使用字符串的str.startswith()和str.endswith()方法

```python
import os, stat

fileList = os.listdir('.')

res = []
for fileName in fileList:

        res.append(fileName)

```

## 3. 调整字符串中文本的格式
+ 使用正则表达式re.sub()方法做字符串替换，利用正则表达式的捕获组，捕获每个部分内容，在替换字符串中调整各个捕获组的顺序

```python
longStr = '''
2018-06-14 15:14:29 hahahehehahaha
2018-10-13 15:14:29 hahahehehahaha
2018-05-23 15:14:29 hahahehehahaha
2018-12-02 15:14:29 hahahehehahaha
2018-05-11 15:14:29 hahahehehahaha
'''
res = re.sub('(\d{4})-(\d{2})-(\d{2})', r'\2/\3/\1', longStr)

# 给每一个组起一个名字
res = re.sub('(?P<year>\d{4})-(?P<month>\d{2})-(?P<day>\d{2})', r'\g<month>/\g<day>/\g<year>', longStr)
print(res)
```

## 4. 将多个小字符串拼接成一个大的字符串
+ 使用`str.join()`方法，更加快速的拼接列表中所有字符串

```python
pl = ['<123>', '<erw>', 125, '<plk>', '<120.0>', '<5874.012>']

print(''.join(str(x) for x in pl))
```

## 5. 对字符串进行左右居中对齐
+ 使用字符串的str.ljust(), str.rjust(), str.center()进行左中右对齐
+ 使用format()方法

```python
user = 'sherry'
print(user.ljust(20, '-'))
print(user.rjust(20, '-'))
print(user.center(20))

print(format(user, '<20'))
print(format(user, '>20'))
print(format(user, '^20'))

w = max(map(len, d.keys()))

for k in d:
    print(k.ljust(w), ': ', d[k])
```

## 6. 去掉字符串中不需要的字符
+ 去掉前后多余的空白字符
+ 过滤windows文本编辑器中的\r
+ 去掉文本中的unicode组合符合(音调)
+ 方法
	- 字符串strip(), lstrip(), rstrip()
	- 删除单个固定位置的字符，可以使用切片 + 拼接的方式
	- 字符串的replace()方或者正则表达式re.sub()删除任意位置字符
	- 字符串translate()方法，可以同时删除不同的字符

```python
s = 'abc:123'
print(s[:3] + s[4:])

s = '\tabc\t123\txyz\nxyq\r'
print(s.replace('\t', ''))

print(re.sub('[\t\n\r]+', '', s))
```
