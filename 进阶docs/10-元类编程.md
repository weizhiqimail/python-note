# 2. [`__getattr__` 和 `__getattribute__`](../code/31-getattr_getattribute.py)
+ `__getattr__` 在查找不到属性的时候调用，查找到的时候不会调用
+ `__getattribute__` 是无条件调用，相当于可以做劫持操作，访问不存在的属性不会操作。尽量不要去修改这个魔法函数，如果控制不好，很容易造成问题

# 3. [属性描述符和属性查找过程](../code/32-property_descriptor.py)
+ 一个类里只要定义了 `__get__`, `__set__` 和 `__delete__` 三个魔法函数，那么这个类就是一个属性描述符
+ 只定义了 `__get__` 的叫做非数据属性描述符
+ 属性描述符的数据查找顺序

# 4. [`__new__` 和 `__init__` 的区别](../code/33-new_init.py)
+ `__new__` 和 `__init__` 的区别是 `__new__` 可以定义类生成的过程，先调用 `__new__` 方法，在 `__new__` 的时候是没有实例的，实例是在`__init__` 的时候生成的 
+ `__new__` 是用来控制对象的生成过程，一般不需要重写
+ `__init__` 是用来完善对象的，如果 new 不返回对象，那么不会调用 init 函数
