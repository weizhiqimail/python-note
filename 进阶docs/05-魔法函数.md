# 2. 什么是魔法函数
+ 类似于 `__xx__` 的函数，以双下划线开头，以双下划线结尾
+ 魔法函数不是当前类的方法，而是所有类都有的魔法函数
+ 魔法函数的目的是为了增强类的功能

# 3. python 的数据模型以及数据模型对 python 的影响
+ 魔法函数实际上是 Python 的数据模型
+ 不需要我们显示的去调用魔法函数
+ 魔法函数实际上一个独立的存在，不归属于类或者 object

# 4. 简单的魔法函数
+ len 方法
    + 如果 x 是一个内置类型的实例，那么 len(x) 的速度就会非常快。原因是 CPython 会直接从一个 C 结构体里读取对象的长度，完全不用调用任何方法。
    + 获取一个集合中元素的数量是很常见的操作，str, list, set, memoryview 等类型，len 操作非常高效
    + 所以 len 不是一个普通的方法，是为了让 Python 自带的数据结构可以走后门，abs 也是同理，但是由于它是特殊方法，我们也可以把 len 用于自定义数据类型。这种处理方式在保持内置类型的效率和保证语言的一致性之间找到了一个平衡点。
+ `__repr__` 魔法函数的目的
    + 如果我们直接输出实例，那么得到的是一个对象和内存地址，如果实现了 `__repr__` 这个方法，就可以在控制台看到我们自己实现的输出结果
    + `__repr__` 所返回的字符串应该准确、 无歧义， 并且尽可能表达出如何用代码创建出这个被打印的对象
+ `__str__` 魔法函数只有 str() 函数被调用，或者是在用 print 函数打印一个对象的时候才会被调用，而且返回的字符串的对终端用户更加友好
+ `__repr__` 和 `__str__` 的区别在于，如果你指向实现这两个特殊方法中的一个，`__repr__` 是更好的选择，因为如果一个对象没有 `__str__` 函数，而 python 又需要调用它的时候，解释器会用 `__repr__` 作为替代。[关于两者的区别的讨论](https://stackoverflow.com/questions/1436703/difference-between-str-and-repr)
+ `__bool__` 魔法函数，默认情况下，我们自己定义的类的实例总是被认为是真的，除非这个类对 `__bool__` 或者 `__len__` 函数有自己的实现。bool(x) 的背后是调用 `x.__bool__()` 的结果。如果不存在 `__bool__` 方法，那么 `bool(x)` 会尝试调用 `x.__len__()` ，如果返回 0，则 bool 返回 False，否则返回 True

# 5. 示例

## 5.1 随机纸牌

```python
import collections
from random import choice

Card = collections.namedtuple('Card', ['rank', 'suit'])

class FrenchDeck():
    ranks = [str(n) for n in range(2, 11)] + list('JQKA')
    suits = 'spades diamonds clubs hearts'.split()
    
    def __init__(self):
        self._cards = [Card(rank, suit) for suit in self.suits for rank in self.ranks]
    
    def __len__(self):
        return len(self._cards)
    
    def __getitem__(self, position):
        return self._cards[position]

    
beer_card = Card('7', 'diamonds')
print(beer_card)

deck = FrenchDeck()

print(choice(deck))
print(choice(deck))
print(choice(deck))
```

## 5.2 向量计算

```python
from math import hypot

class Vector:
    def __init__(self, x = 0, y=0):
        self.x = x
        self.y = y
    
    def __repr__(self):
        return 'Vector(%r, %r)' % (self.x, self.y)
    
    def __abs__(self):
        return hypot(self.x, self.y)
    
    def __bool__(self):
        return bool(self.x or self.y)
    
    def __len__(self):
        return abs(self.x - self.y)


    def __add__(self, other):
        x = self.x + other.x
        y = self.y + other.y
        return Vector(x, y)
    
    def __mul__(self, scalar):
        return Vector(self.x * scalar, self.y * scalar)
    
v1 = Vector(1, 2)
print(v1)
v2 = Vector(3, 4)
print(abs(v2 * 3))
print(v1 + v2)
```
