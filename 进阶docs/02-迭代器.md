## 1. 迭代器对象
+ list和字符串都是可迭代对象
+ `iter(l)`实际上在`l`内部调用的是`l.__iter__()`方法
+ `__iter__`是可迭代的接口
+ 在字符串内部没有`__iter__`方法，字符串使用的是`__getitem__`这个方法
+ 可迭代对象可以使用`next()`属性获取下一个值，如果最后一个值，如果继续`next()`，就会报`stop

```python
l = [1, 2, 3, 4]
s = 'abcdefg'
for x in l:
    print(x)
print(iter(l))
print(l.__iter__)
print(iter(s))
print(s.__getitem__)
```

## 2. 把`__iter__`实现成生成器函数

```python
class PrimerNumber:
    def __init__(self, start, end):
        self.start = start
        self.end = end

    def isPrimerNumber(self, k):
        if k == 1:
            return False
        if k == 2:
            return False
        for i in range(2, k):
            if k % i == 0:
                return False

            return True

    def __iter__(self):
        for k in range(self.start, self.end + 1):
            if self.isPrimerNumber(k):
                yield k


nums = PrimerNumber(1, 100)
for num in nums:
    print(num)
```

## 3. 反向迭代

```python
class FloatRange:
    def __init__(self, start, end, step=0.1):
        self.start = start
        self.end = end
        self.step = step

    def __iter__(self):
        t = self.start
        while t <= self.end:
            yield t
            t += self.step

    def __reversed__(self):
        t = self.end
        while t >= self.start:
            yield t
            t -= self.step


floatRange = FloatRange(1.0, 4.0, 0.5)

for x in iter(floatRange):
    print(x)

print('*' * 20)

for x in reversed(floatRange):
    print(x)
```

## 4. 对迭代器进行切片

```python
from itertools import islice

f = open('./url_manager.py')

# islice的参数不能为负数
# 指定输出固定的行
lines = islice(f, 21, 25)
for line in lines:
    print(line)

# 指定输出前10行
lines1 = islice(f, 10)

# 指定输出第10行到结束
lines2 = islice(f, 10, None)

# islice是一个迭代器，每次迭代都会消耗原对象
```

## 5. 在for中迭代多个迭代对象

```python
from random import randint
from itertools import chain

chinese = [randint(60, 100) for x in range(50)]
math = [randint(60, 100) for y in range(50)]
english = [randint(60, 100) for z in range(50)]

total = []
# 并行，使用内置函数zip，能将多个可迭代对象合并，每次迭代返回一个元组
for c, m, e in zip(chinese, math, english):
    print(c + m + e)

# 串行，使用标准库中的itertools.chain，它能将多个可迭代对象连接
e1 = [randint(60, 100) for x in range(30)]
e2 = [randint(60, 100) for x in range(40)]
e3 = [randint(60, 100) for x in range(50)]
e4 = [randint(60, 100) for x in range(60)]
count = 0
for s in chain(e1, e2, e3, e4):
    if (s > 90):
        count += 1

print(count)
```
