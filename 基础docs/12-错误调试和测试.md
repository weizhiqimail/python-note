## 1. 错误和异常的基本概念
+ 语法错误：代码不符合解释器或者编译器语法
+ 逻辑错误：不完整或者不合法输入或者计算出现问题
+ 异常：执行过程中出现问题而导致程序无法执行
    - 程序遇到逻辑或者算法问题
    - 运行过程中计算机错误(内存不够或者IO错误)
+ 错误：
    - 代码运行前的语法或者逻辑错误
    - 语法错误在执行前修改，逻辑错误无法修改
+ 异常分为两个步骤
    - 异常产生，检查到错误且解释器认为是异常，抛出异常
    - 异常处理，截获异常，忽略或者终止程序处理异常


## 2. 常见的错误
+ NameError，变量没有定义，直接在代码中使用`a`
+ SyntaxError，语法错误，比如`if a`
+ IOError，IO错误，比如打开一个不存在的问题
+ ZeroDivisionError，除零错误
+ ValueError，值错误，比如说`a = int('aaa')`
+ KeyboardInterrupt，键盘错误，当前进程没有结束，就Ctrl + C


#### 2.1 捕获错误
+ 高级语言都内置了一套`try...expect...finally...`的错误处理机制
```python
import random 

num = random.randint(0, 100)

while True:
	try:
		guess = int(input('Enter 1 ~ 100:'))
	except ValueError as e:
		print('Enter 1 ~ 100')
		continue
	if guess > num:
		print('guess bigger', guess)
	elif guess < num:
		print('guess smaller', guess)
	else:
		print('Guess Ok, Game Over')
		break
	print('\n')
```

+ `try- finally`
    + 如果try语句中没有捕获错误，代码执行finally里的语句
    + 如果try语句中捕获错误，程序首先执行finally里边的语句，然后将捕获到的错误交给python解释器执行
    + 所以，无论是否有错误，都会执行finally代码
    + 作用，为异常处理事件提供清理机制，用来关闭文件或者释放系统资源


+ 如果没有错误，`except`语句块后边加一个`else`，当没有错误发生时，会自动执行`else`语句

```python
print('START...')
try:
    print('try...')
    r = 10 / 2
    print('result:', r)
except ZeroDivisionError as e:
    print('except: ', e)
else:
    print('no error')
finally:
    print('finally')
print('END...')
```
+ Python的错误也是`class`，所有的错误类型都继承自`BaseException`，所以在使用`except`的时候要注意的是，它不但捕获该类型的错误，还把他的子类的错误也捕获到
+ 出错的时候，一定要分析错误的调用栈信息，才能定位错误的位置

#### 2.2 记录错误
+ 我们需要捕获错误，把错误堆栈打印出来，分析错误原因，同时让程序继续执行
+ Python内置的`logging`模块可以非常容易的记录错误信息

```python
import logging

print('START')


def foo(s):
    return 10 / int(s)


def bar(s):
    return foo(s) * 2


def main():
    try:
        bar('0')
    except Exception as e:
        logging.exception(e)


main()
print('END')

```
#### 2.3 错误处理
+ 捕获错误的目的只是记录一下，便于后续追踪，由于当前函数不知道该如何吹该错误，就继续往上抛，让顶层调用者去处理。
+ `raise`语句如果不带参数，就会把当前错误原样抛出
+ 在`except`和`raise`一个error，还可以把一种类型的错误转换为另一种类型

```python
def foo(s):
    n = int(s)
    if n == 0:
        raise ValueError('invalid value: %s' % s)
    return 10 / n

def bar():
    try:
        foo('0')
    except ValueError as e:
        print('value error')
        raise

bar()
```

#### 2.4 try-except-else-finally
+ 如果try语句没有捕获到异常，try执行完毕后，执行else，最后执行finally
+ 如果try语句捕获到错误，那么就执行对应的except，最后执行finally

```python
try:
	f = open('./a.txt')
	print(int(f.read()))
except IOError as e:
	print('IOError', e)
except ValueError as e:
	print('ValueError', e)
else:
	print('else sentence')
finally:
	try:
		print('file close')
		f.close
	except NameError as e:
		print('Name Error', e)
```

## 3. with语句
```python
with context [as var]:
    with_suite
```

+ `with`语句用来代替`try-except-finally`语句，使代码更加简洁
+ `context`表达式返回的是一个对象
+ `var`用来保存`context`返回对象，单个返回值或者元组
+ `with_suite`使用`var`变量来对`context`返回对象进行操作
+ `with`语句实质是上下文管理
    - **上下文管理协议**：包含方法`__enter__()`和`__exit__()`，支持该协议的对象要实现这两个方法
    - **上下文管理器**：定义执行with语句时要建立的运行时上下文，负责执行with语句块上下文中的进入与退出的操作
    - **进入上下文管理器**：调用管理器`__enter__`方法，如果设置了`as var`语句，`var`变量就会接受`__enter__()`方法返回值
    - **退出上下文管理器**：调用管理器`__exit__()`方法

```python
class Stu(object):
	def __init__(self, name):
		self.name = name
		print('__init__')

	def __enter__(self):
		print('__enter__')
		return self

	def do_self(self):
		print('do_self')

	def __exit__(self, exc_type, exc_value, traceback):
		print('__exit__')
		print('Error', exc_type, 'info:', exc_value)

with Stu('text context message') as f:
	print('f.name: ', f.name)
	f.do_self()

#  __init__
#  __enter__
#  f.name:  text context message
#  do_self
#  __exit__
#  Error None info: None
```

+ `with`语句应用场景
    - 文件操作
    - 进程线程之间互斥对象，例如互斥锁
    - 支持上下文的其他对象


## 4. assert和raise
#### 4.1 raise
+ raise语句用于主动抛出异常
+ 语法格式：raise [exception, args] 
+ exception:异常类
+ args:描述异常信息的元组

#### 4.2 assert
+ 断言，用于检测表达式是否为真，如果为假，引发`AssertionError`错误
+ 语法格式：assert expresion [args]
+ expresstion:表达式
+ args：判断错误后显示的内容

## 5. 异常
#### 5.1 标准异常
+ python内建异常，程序执行前就已经存在
+ 所有异常基类(BaseException)
    - 用户中断Ctrl + C(KeyboardInterrupt)
    - 常见错误的基类(Exception)
        + SyntaxError
        + NameError
        + IOError
        + ImportError
    - Python解释器退出(SystemExit)

#### 5.2 自定义异常
+ 用于描述python中没有涉及到的异常
+ 自定义异常必须继承Exception类
+ 自定义异常只能主动触发
+ 实现异常`class FileError(IOError):pass`
+ 触发异常`raise FileError, 'text FileError'`

## 6. 测试
+ 简单粗暴有效的方法，使用`print()`
+ 使用`assert`断言，如果断言失败，`assert`语句就会抛出`AssertionError`，启动Python解释器的时候可以用`-0`参数来关闭`assert`

```python
def foo(s):
    n = int(s)
    assert n != 0, 'n is zero'
    return 10 / n
foo('0')
```
+ `logging`，不会抛出错误，而且可以输出到文件，`logging`可以指定记录信息的级别，有`debug`，`info`，`warning`，`error`等几个级别。`logging`的另一个好处就是通过简单的配置，一条语句可以同时输出到不同的地方

```python
import logging

logging.basicConfig(level=logging.INFO)
s = '0'
n = int(s)
logging.info('n = %d' % n)
print(10 / n)
```
+ `pdb`调试器，让程序以单步方式运行，可以随时查看运行状态
    - 在启动的时候，加入参数`-m pdb`
    - 输入`l`查看代码
    - 输入`n`可以单步执行代码
    - 输入`p 变量名`查看变量
    - 输入`q`结束调试

```python
s = '0'
n = int(s)
print(10 / n)
```
+ `pdb.set_trace()`不需要单步执行，在可能出错的地方方一个`pdb.set_trace()`即可设置一个断点
    - 运行代码，通过命令`p`查看变量
    - 通过命令`c`继续运行
    - 

```python
import pdb

s = '0'
n = int(s)
pdb.set_trace()
print(10 / n)
```
