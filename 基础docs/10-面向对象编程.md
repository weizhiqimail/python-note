## 1. 面向对象编程
+ 面向对象编程OOP，是一种程序设计思想。OOP把对象作为程序的基本单元，一个对象包含了数据和操作数据的函数。
+ 面向过程的程序设计把计算机程序视为一系列的命令集合，即一组函数额顺序执行。为了简化程序设计，面向过程把函数继续切分为子函数，即把大块函数通过切割成小块函数来降低系统的复杂度。
+ 面向对象的程序设计把计算机程序视为一组对象的集合，而每个对象都可以接收其他对象发过来的消息，并处理这些消息，计算机程序的执行就是一些列消息在各个对象之间的传递。
+ 在Python中，所有数据类型都可以视为对象，也可以自定义对象，自定义的对象数据类型就是面向对象中类的概念

## 2. 例子
+ 处理学生的成绩

```python
#!usr/bin/env python3
# -*- coding: utf-8 -*-

mark = {
    'name': 'mark',
    'score': 98
}

jack = {
    'name': 'mark',
    'score': 97
}

def getScore(stu):
    print('%s:%s'%(stu['name'], stu['score']))

getScore(mark)
getScore(jack)
```
+ 如果采用面向对象的程序设计思想，首先需要思考的不是程序的执行流程，而是`Student`这种数据类型该如何被视为一个对象，这个对象拥有`name`和`score`两个属性`property`，如果要获取一个学生的成绩，首先必须创建出这个学生对应的对象，然后再给这个对象发送一个`getScore`的消息，让对象自己把自己的数据打印出来。

```python
class Student(object):
    def __init__(self, name, score):
        self.name = name
        self.score = score

    def getScore(self):
        print(self.name, ':', self.score)

mark = Student('mark', 98)
sherry = Student('sherry', 95)
mark.getScore()
sherry.getScore()
```
+ 给对象发消息实际上就是调用对象对应的关联函数，称之为对象的方法`method`，面向对象的程序就是如此。
+ 面向对象的抽象成都比函数要高，因为一个`Class`既包含数据，又包含操作数据的方法
+ 数据封装，继承，多态是面向对象的三大特点。

## 3. 类和实例
+ 面向对象最重要的概念就是类`class`和实例`instance`，类是抽象的模板，而实例是根据类创建出来的一个具体的对象，每一个对象都拥有相同的方法，但是各自的数据可能不同。

```python
class Student(object):
    pass
```
+ `class`后面紧接着是类名，即`Student`类，类名通常大写开头的单词，紧接着是`(object)`，表示该类是从哪个类继承下来的。如果没有合适的继承类，就使用`object`类，这是所有类最终都会继承的类。
+ 定义好了`Student`类，就可以根据`Student`类创建出一个实例，创建实例是通过类名+()实现的

```python
mark = Student()
print(mark)

// <__main__.Student object at 0x0540E4B0>
// 后边的是mark实例所在的内存地址，每一个object的地址都不一样，而Student是一个类
```
+ 可以自由的修改一个实例的属性值
+ 由于类可以起到模板的作用，因此在创建实例的时候，可以把一些必须绑定的属性强制写进去，通过定义一个特殊的`__init__`方法，在创建实例的时候，就把`name``score`属性绑定上去
 
```python
class Student(object):
    def __init__(self,name, score):
        self.name = name
        self.score = score
```
+ 注意，`__init__`的第一个参数永远是`self`，表示创建的实例本身，因此在`__init__`内部，就可以把各种属性绑定到`self`上
+ 有了`__init__`方法，在创建实例的时候，就不能传入空的参数，必须传入与`__init__`方法匹配的参数，但是`self`参数不需要传入

+数据封装，面向对象编程的一个重要特点就是数据封装，上边的`Student`类红，每一个实例就拥有各自的`name`和`score`这些数据。

```python
class Student(object):
    def __init__(self,name, score):
        self.name = name
        self.score = score

    def getScore(self):
        print(self.name, ':', self.score)
```

## 4. 访问限制
+ 如果要让内部属性不被外部访问，就可以把属性的名称前加上两个下划线`__`，实例的变量名如果以`__`开头，就变成了一个私有变量，只有内部可以访问，外部能访问。

```python
class Student(object):
    def __init__(self, name, score):
        self.__name = name
        self.__score = score

    def getScore(self):
        print(self.__name, ':', self.__score)


mark = Student('mark', 98)
sherry = Student('sherry', 95)
# print(mark.__name)
# 报错，外部无法访问到内部的实例变量
mark.getScore()
sherry.getScore()

```
+ 通过访问限制的保护，代码可以更加强壮
+ 如果外部要访问内部的`__name`和`__score`，可以给`Student`类增加`getName()`和`getScore()`方法，如果要修改内部变量的值，那么就可以增加一个`setName()`和`setScore()`方法

```python
class Student(object):
    def __init__(self, name, score):
        self.__name = name
        self.__score = score

    def getScore(self):
        return self.__score

    def getName(self):
        return self.__name

    def setScore(self, score):
        self.__score = score

    def setName(self, name):
        self.__name = name


mark = Student('mark', 98)
sherry = Student('sherry', 95)
mark.setName('tom')
print(mark.getName())
sherry.setScore(98)
print(sherry.getScore())

```
+ 不能直接访问`__name`是因为Python解释器对外把`__name`变量改成了`_Student_name`，所以仍然可以通过`_Student_name`来访问`__name`变量，但是不要这么做，因为不同版本的Pythonn解释器可能会把`__name`改成不同的变量名。
+ 也就是说，Python本身没有任何机制阻止，一切都依靠自觉

```python
mark = Student('mark', 98)
sherry = Student('sherry', 95)
print(mark.getName())
mark.__name = 'new mark'
print(mark.__name)

# 注意，这里的mark.__name和Class类中的__name不是一个变量，在Class类内部，已经把__name编译成了_Student_name了。
```
## 5. 继承和多态
+ 在OOP程序设计中，定义一个`class`的时候，可以从某个现有的`class`继承，新的`class`称为子类`subclass`，而被继承的`class`称为基类、父类或者超类`base class` `super class`
+ 继承最大的好处就是子类可以获取父类所有的功能。

```python
class Animal(object):
    def run(self):
        print('animal run function')

class Dog(Animal):
    pass

class Cat(Animal):
    pass

dog = Dog()
dog.run()

cat = Cat()
cat.run()
```
+ 当子类和父类都存在相同的`run()`方法时，子类`run()`覆盖了父类的`run()`，在代码运行时，总是会调用子类的`run()`，这就是继承的另一个好处：`多态`
+ 定义一个`class`的时候，实际上就定义了一种数据类型，这种数据类型和Python自带的数据类型，比如`list``dict``str`没有什么区别

```python
class Animal(object):
    def run(self):
        print('animal run function')

class Dog(Animal):
    def run(self):
        print('dog is running')

class Cat(Animal):
    def run(self):
        print('cat is running')
dog = Dog()
dog.run()

cat = Cat()
cat.run()
```
+ 判断一个变量是否是某个类型可以用`isinstance`判断
+ 这个`dog`不仅仅是`Dog`类型，还是`Animal`类型
+ 所以，在继承关系中，如果一个私立的数据类型是某个子类，那么他的数据类型也可以被看做是父类

```python
print(isinstance(dog, Dog)
```
+ 普通函数传入`class`参数

```python
class Animal(object):
    def run(self):
        print('animal run function')

class Dog(Animal):
    def run(self):
        print('dog is running')

class Cat(Animal):
    def run(self):
        print('cat is running')
dog = Dog()
dog.run()

cat = Cat()
cat.run()


def run_twice(animal):
    animal.run()
    animal.run()

run_twice(Dog())
run_twice(Cat())
run_twice(Animal())
```
+ 静态语言和动态语言
    - 对于静态语言来说，如果需要传入`Animal`类型，则传入的对象必须是`Animal`类型或者他的子类，不然无法调用`run()`方法
    - 对于Python这类动态语言来讲，不一定要传入`Animal`类型，只需要保证传入的对象有一个`run()`方法即可
    - 所以，对于动态语言来讲，这就是动态语言的鸭子类型，它并不要求严格的继承体系，一个对象只要“看起来像鸭子，走起路来像鸭子”，那它就可以被看做是鸭子
    - Python的`file-like-object`就是一种鸭子类型，对真正的文件对象，他有一个`read()`方法，返回其内容，但是很多对象，只要有`read()`方法，都可以被视为`file-like-object`。很多函数接收的参数就是`file-like-object`，对于传入的参数，不一定是真正的文件对象，只要传入了任何实现了`read()`方法的对象即可

+ 继承可以把父类的所有功能都直接拿过来，这样就不必从零写，子类只需要新增自己特有的方法，也可以把父类不合适的方法覆盖重写。
+ 动态语言的鸭子类型特点决定了继承不像静态语言那样是必须的

+ 使用`dir`获取一个对象的所有属性和方法

```python
class Animal(object):
    def run(self):
        print('animal run function')


print(dir(Animal))
print(dir('hello'))
print(dir(123))
print(dir(True))
print(dir((1, 2, 3)))
print(dir([1, 2, 3]))
```
+ 类型`__xxx__`的属性和方法在Python中都是有特殊用途的。比如`__len__`方法返回长度。如果调用`len()`方法获取一个对象的长度，实际上，在`len()`内部，是自动调用该对象的`__len__`方法。

```python
print(len('123'))
print('123'.__len__())
```
+ 列出对象的属性和方法，还需要配合`getattr()``setattr()`和`hasattr()`，直接操作一个对象的状态
+ 如果试图获取不存在的属性，就会抛出`AttributeError`错误
+ `getattr()`可以传入一个默认值，`getattr(mark ,'x', 100)`这句话的意思就是说，如果在`mark`属性下有`x`这个值，那么就会返回这个值，如果`mark`属性下没有`x`这个值，那么就会返回设置的这个默认值`100`

```python
class Student(object):
    def __init__(self):
        self.x = 10

    def power(self):
        return self.x * self.x

mark = Student()
print(hasattr(mark, 'x'))
print('mark.x: ', mark.x)
print(hasattr(mark, 'y'))

setattr(mark, 'y', 15)
print('mark.y: ', mark.y)
```
+ 只有在不知道对象的属性的时候，才要使用`hasattr`等方法，如果明确知道了，就不要使用

## 7. 实例属性和类属性
+ 给实例绑定属性的方法是通过实例变量，或者通过`self`变量

```python
class Student(object):
    def __init__(self, name):
        self.name = name

s = Student('Mark')
s.score = 100
```
+ `class`类的属性

```python
class Student(object):
    name = 'Student name'
    def __init__(self, name):
        self.name = name

s = Student('Mark')
s.score = 100
print(s.name)
s.name = 'Sherry'
print(s.name)
del s.name # 删除对象的属性
```
+ 当删除实例的属性，实例再去获取这个属性，得到的将是类的属性
