## 1. 条件判断
```python
age = input('age: ')
age = int(age);
if age >= 18:
    print('your age is ', age);
elif age >= 6:
    print('you are teenager');
else:
    print('you are child');
```

## 2. 循环

```python
names = ['mark', 'sherry', 'you'];

for name in names:
    print('name: ', name);
```

## 3. range
```python
num = list(range(1,101));
sum = 0;
for x in num:
    if x == 5:
        continue;
    if x == 10:
        break; # 退出循环
    sum += x;

print(sum);
```
