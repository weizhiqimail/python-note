# 1. 字符串编码
+ 在最新的 Python3 中，字符串是以unicode编码的，也就是说，Python 的字符串支持多语言。
+ 对于单个字符的编码，Python提供了 ord() 函数获取字符的整数表示， chr() 函数把编码转成相应的字符
+ 如果知道字符的整数编码， 还可以使用十六进制写

```python
print(ord('H')) # 72
print(chr(72))  # H
print('\u4e2d\u6587') # 中文
```

+ 由于Python的字符串类型是 str，在内存中以 Unicode 表示，一个字符对应若干个字节。如果要在网络传输，或者保存在磁盘上，就需要把 str 变为以字节为单位的 bytes 
+ Python对 bytes 类型的诗句用带 b 前缀的单引号或双引号表示。 bytes 的每个字符只占用一个字节。

```python
x = b'ABCDEFG'
y = 'ABCDEFG'
```

+ 以 unicode 表示的 str 通过 encode() 方法可以编码为指定的 bytes ， decode() 方法可以把 bytes 转换为 unicode 码，如果 bytes 中有无法解码的字节， decode() 就会报错

```python
# encode
x = 'ABCDEFG'
print(x.encode('ascii'))
print(x.encode('utf-8'))
y = '你好呀'
# print(y.encode('ascii')) # 报错，因为ascii表里没有中文字符
print(y.encode('utf-8'))

# b'ABCDEFG'
# b'ABCDEFG'
# b'\xe4\xbd\xa0\xe5\xa5\xbd\xe5\x91\x80'

# decode
x = b'ABCDEFG'
print(x.decode('ascii'))
y = b'\xe4\xbd\xa0\xe5\xa5\xbd\xe5\x91\x80'
print(y.decode('utf-8'))

# ABCDEFG
# 你好呀
```

+ 计算字符数使用 len() ， bytes 计算字节数

```python
print(len(b'ABCDEFG'))
print(len('你好呀'))
print(len(b'\xe4\xbd\xa0\xe5\xa5\xbd\xe5\x91\x80'))
```

+ 格式化
如果不太确定应该用什么， %s 永远起作用，他会把任何数据类型都转换为字符串

占位符 | 替换内容
---|---
%f | 浮点数
%d | 整数
%s | 字符串
%x | 十六进制整数

```python
print('%d-%d' %(3, 1))
print('%0d-%0d' %(3, 1))
print('%02d-%02d' %(3, 1))
```

+ 使用 format() 格式化
```python
print('Hello, {0}, this is {1} apples'.format('mark', 5))

# Hello, mark, this is 5 apples
```
