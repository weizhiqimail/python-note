## 1. 正则表达式
+ 正则表达式是一种用来匹配字符串的强有力的工具，设计思想是用一种描述性的语言来给字符串定义一个规则，凡是符合规则的字符串，就认为已经匹配
+ `\d`匹配一个数字
+ `\w`匹配一个字母或数字
+ `\s`匹配一个空格，包括Tab字表福
+ `\s+`表示至少有一个空格，例如`' '`
+ `|`可以匹配`A|B`中的`A`或`B`
+ `^`表示以什么开头
+ `^\d`表示必须以数字开头
+ `$`表示以什么结尾
+ `$\d`表示必须以数字结尾
+ `.`匹配任意字符
+ `*`匹配任意个字符(包括0个)
+ `+`表示至少匹配一个字符
+ `?`表示0个或1个字符
+ `{n}`表示n个字符
+ `{n,m}`表示n-m个字符
+ 匹配电话号码`021-12345`，正则式`\d{3}\-\d{3,8}`


## 2. 进阶
+ 要做出精确的匹配，可以使用`[]`表示范围
+ `[0-9a-zA-Z\_]`可以匹配一个数字，字母或下划线
+ `[0-9a-zA-Z\_]`可以匹配至少一个数字，字母或者下划线组成的字符串
+ `[0-9A-Z\_][0-9a-zA-Z\_]`可以匹配由字母或下划线开头，后边任意一个由数字字母或者下户线租饿成字符串
+ `[a-zA-Z\_][0-9a-zA-Z\_]{0,19}`精确地限制了变量的长度是1-20个字符

## 3. re模块
+ re模块包含所有正则表达式的功能，由于Python的字符串自身也支持`\`转义，所以要注意`NAME\\MARK`，对应的字符串内容是`NAME\MARK`
+ 所以使用`r`前缀，就不需要考虑转义的问题`r'NAME\MARK'`
+ `match`方法判断是否匹配，如果匹配成功，返回一个`Match`对象，否则返回`None`

```python
import re
str = r'^\d{3}\-\d{3,8}$'
num = '021-12345'
print(re.match(str, num))
```

## 4. 切分字符串
+ 普通方法切分字符串`'a,b,c,d'.split(',')`，返回一个`list`,`['a', 'b', 'c', 'd']`
+ 如果有多个`,`，`'a,b,c,,,d'.split(',')`，那么分割的结果是`['a', 'b', 'c', '', '', 'd']`
+ 更好的方法是采用正则表达式`re.split(r'[\s\,]+', 'a,b,c,d,,,,,e')`，结果是`['a', 'b', 'c', 'd', 'e']`
+ 还可以再添加一个分割标识符`;`，`re.split(r'[\s\,\;]+', 'a,b,c;d,,,,,e;f')`，结果是依然可以分隔开`['a', 'b', 'c', 'd', 'e', 'f']`

## 5. 分组
+ 正则表达式还有提取子串的功能，用`()`表示的就是要提取的分组(group)
+ `^(\d{3})-(\d{3,8})$`分别定义了两个组

```python
import re
g = re.match(r'^(\d{3})-(\d{3,8})$', '010-12345')
print(g.group(0))  # 原始字符串
print(g.group(1))  # 第一个分组
print(g.group(2))  # 第二个分组
```

## 6. 贪婪匹配
+ 正则匹配默认是贪婪匹配，就是尽可能的匹配多的字符

```python
re.match(r'^(\d+)(0*)$', '123456000000').groups()
# ('123456000000', '')
```
+ `\d+`采用的就是贪婪匹配
+ 如果要惰性匹配，那么就把`\d+`改成`\d+?`

```python
re.match(r'^(\d+?)(0*)$', '123456000000').groups()
# ('123456', '000000')
```

## 7. 编译
+ Python使用正则表达式的时候，`re`模块做了两件事
    - 编译正则表达式，如果正则不合法，报错
    - 变异后的正则去匹配字符串
+ 如果一个正则要使用很多次，出于效率的考虑，可以预编译正则，那么重复使用的时候就不需要编译了，直接匹配

```python
tel = re.compile(r'^(\d{3})-(\d{3,8})$') # 编译
tel.match('021-12345').groups() # 获取匹配的结果
```
+ 编译后生成的正则对象，由于该对象已经包含了正则，所以调用对应的方法时不用给出正则表达式
