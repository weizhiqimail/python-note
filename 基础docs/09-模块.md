## 1. 模块
+ 在Python中一个`.py`文件就是一个模块`module`
+ 使用模块最大的好处就是大大提高了代码的可维护性。其次，当一个模块编写完毕，就可以被其他地方引用，在编写模块的时候必须koala名字是否会和其他模块的名字冲突。注意，尽量不要与内置函数名字冲突。
+ 使用模块还可以避免函数名月变量名冲突。相同名字的额函数和变量完全可以分别存储在不同的模块中。
+ 为了避免模块名相同，Python引入了按目录来组织模块的方法，叫做包`package`
+ 每一个包目录下都会有一个`__init__.py`文件，这个文件是必须的。否则Oython就会把这个目录当做普通目录，而不是一个包。`__init__.py`可以是一个空文件，也可以有代码。

## 2. 作用域
+ 函数和变量仅仅在模块内部使用，通过`_`前缀来实现
+ 正常的函数和变量名都是公开的，可以被直接引用
+ 类似`__xx__`这样的变量是特殊变量，可以被直接引用，但是也有特殊用途。比如上边的`__author__`和`__name__`就是特殊变量，模块内部定义的文件注释变量可以用特殊变量`__doc__`访问，自己定义的变量不要用这种方式。
+ 类似于`_xxx`和`__xx`这样的函数或变量就是私有的，不应该被直接引用。
+ Python函数和变量不应该被直接引用，而不是不能被直接引用，因为Python内部并没有一种方法可以完全限制访问private函数，但是，从编程习惯上不应该引用private函数或变量。
+ 外部不需要引用的函数全部定义为private，只有外部需要引用的函数才定义为public
