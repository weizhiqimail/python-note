## 1. 列表生成式
+ 如果`list`中既包含字符串，又包含整数，由于非字符串类型没有`lower`方法，所以列表生成式会报错
+ 使用Python内置的`isinstance`判断一个变量是不是字符串`isinstance('hello', str)`

```python
print(list(range(1, 11)))
L = [x * x for x in range(1, 11) if x % 2 == 0]
print(L)

P = [m + n for m in 'ABC' for n in 'XYZ']
print(P)

import os

O = [d for d in os.listdir('.')]
print(O)
O = [d for d in os.listdir('..')]
print(O)
O = [d for d in os.listdir('../../')]
print(O)

D = {
    'user': 'mark',
    'age': '18',
    'home': 'china'
}
U = [k + '=' + v for k,v in D.items()]
print(U)

L = ['AX', 'AY', 'AZ', 'BX', 'BY', 'BZ', 'CX', 'CY', 'CZ']
print([s.lower() for s in L])
print([s.lower() for s in L if isinstance(s, str)])
```

## 2. 生成器
+ 通过列表生成式，可以直接创建一个列表。但是由于内存限制，列表容量肯定是有限的。而且创建一个包含100万个元素的列表，不仅占用很大的内存空间，如果我们仅仅需要访问前面几个元素，那后边绝大多数元素占用的空间都白白浪费掉了。
+ 如果列表元素按照某种元素推算出来，那么我们可以在循环的过程中不断推算出后续的元素，从而节省大量的空间，在Python中，这种一边循环一边计算的机制，成为生成器`generator`
+ 创建`generator`的方法有很多，最简单的一种方法就是把列表生成式的`[]`改成`()`，就可以创建一个`generator`
+ `generator`保存的是算法，每次调用`next(g)`，就计算出`g`的下一个元素的值，直到计算到最后一个元素时，没有更多的元素，抛出`StopIteration`错误
+ 为了简洁，我们可以采用`for`循环进行迭代，使用`for`循环，不需要担心`StopIteration`错误

```python
g = (x * x for x in range(1, 11))
for n in g:
    print(n)
```

+ 杨辉三角问题

```python
def triangles():#杨辉三角
    L = [1]
    while True:
        yield L
        L = [([0] + L)[i] + (L + [0])[i] for i in range(len(L) + 1)]

n = 0
results = []
for t in triangles():
    print(t)
    results.append(t)
    n = n + 1
    if n == 10:
        break
```

## 3. 迭代器
+ `for`循环的数据类型
    - 集合数据类型，`list``tuple``dict``set``str`等
    - 生成器`generator`包括生成器和带`yield`的`generator function`
    - 这些可以直接作用于`for`循环的对象统称为可迭代对象`Iterator`
    - 使用`isinstance()`判断一个对象是不是`Iterable`对象

```python
from collections import Iterable
from collections import Iterator

print(isinstance([], Iterable));  # True
print(isinstance((), Iterable));  # True
print(isinstance({}, Iterable));  # True
print(isinstance(set(), Iterable));  # True
print(isinstance('you', Iterable));  # True
print(isinstance((x for x in range(10)), Iterable));  # True

print(isinstance([1, 2, 3], Iterator));  # False
print(isinstance((1, 2, 3), Iterator));  # False
print(isinstance({'user': 'mark'}, Iterator));  # False
print(isinstance(set(), Iterator));  # False
print(isinstance('you', Iterator));  # False
print(isinstance((x for x in range(10)), Iterator));  # True
```
+ 可以被`next()`函数调用并且不断返回下一个值得对象成为迭代器`Iterator`
+ 可以使用`isinstance()`判断一个对象是否是`Iterator`
+ `list`,`dict`,`str`是`Iterable`，但不是`Iterator`
+ 把`list`,`dict`,`str`等`Iterable`变成`Iterator`可以使用`iter()`函数
+ 之所以他们不是`Iterator`，这是因为Python中的`Iterator`对象表示的是一个数据流，`Iterator`对象可以被`next()`函数调用并不不断返回下一个数据，直到没有数据时抛出`StopIteration`错误。可以把这个数据流看做是一个有序序列，但我们却不能提前直到序列的长度，只能不断通过`next()`函数实现按需计算下一个数据，所以`Iterator`的计算是惰性的，只有在需要返回下一个数据时才会计算
+ `Iterator`甚至可以表示一个无限大的数据流，例如全体自然数，但是使用`list`时永远不可能存储全体自然数的。
+ Python的`for`循环本质上是通过不断调用`next()`来实现的
