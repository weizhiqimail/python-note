##  1. 使用`_slots__`
+ 如果想要限制实例的属性，假如说只允许对`Student`实例添加`name`和`age`属性
+ 为了达到限制的目的，Python允许在定义`class`的时候，定义一个特殊的`__slots__`变量，用来限制该`class`实例能添加的属性

```python
class Student(object):
    __slots__ = ('name', 'age')

mark = Student()
mark.name = 'mack'
mark.age = 19
# mark.score =100
# 报AttributeError错误
```
+ 使用`__slots__`需要注意的是，`__slots__`定义的属性仅仅对当前实例起作用，对继承的子类是不起作用的

```python
class Student(object):
    __slots__ = ('name', 'age')

mark = Student()
mark.name = 'mack'
mark.age = 19

class Mark(Student):
    pass

g = Mark()
g.score = 100
```

## 2. 使用`@property`
+ 在绑定属性时，如果直接把属性暴露出去，虽然写起来简单，但是没有办法检查参数，导致属性可以随便修改
+ 为了限制属性值，可以通过一个`setScore`方法来设置，再通过`getScore`获取

```python
class Student(object):
    def getScore(self):
        return self._score

    def setScore(self, value):
        if not isinstance(value, int):
            raise ValueError('_score must be an integer')
        if value < 0 or value > 100:
            raise ValueError('score must between 0 - 100')
        self._score = value

mark =Student()
mark.setScore(12)
```
+ 但是这么调用又显得很复杂，没有直接用属性简单
+ 所以，使用装饰器`@decorator`中的`@property`，`@property`装饰器就是负责把一个方法变成属性调用的

```python
class Student(object):
    @property
    def score(self):
        return self._score

    @score.setter
    def score(self, value):
        if not isinstance(value, int):
            raise ValueError('_score must be an integer')
        if value < 0 or value > 100:
            raise ValueError('score must between 0 - 100')
        self._score = value

mark = Student()
mark.score = 100
```
+ `@property`的实现比较复杂，把一个`getter`方法变成属性，只需要加上`@property`就可以，此时`@property`本身又创建了另外一个装饰器`@score.setter`负责把一个`setter`方法变成属性赋值。
+ 注意这个`@property`，在对实例属性操作的时候，就知道属性很可能不是直接暴露的，而是通过`getter`和`setter`方法来实现的
+ 还可以定义只读属性，只定义`getter`方法，不定义`setter`方法就是一个只读属性

```python
class Studeng(object):

    @property
    def birth(self):
        return self._birth

    @birth.setter
    def birth(self, value):
        self._birth = value

    @property
    def age(self):
        return 2018 - self._birth
```
+ 上边的`birth`就是可读可写属性，而`age`就是一个只读属性。
+ `@property`广泛应用在类的定义中，可以让调用者写出简短的代码，同时保证对参数进行必要的检查，这样程序运行时就减少了出错的可能性

## 3. 多重继承
+ 多重继承，一个子类可以同时获得多个父类的所有功能
+ `Mixin`在设计类的继承关系的时候，通常主线都是单一继承下来的，但是如果要混入额外的功能，通过多重继承就可以实现，这种设计称为`Mixin`
+ `Mixin`的目的就是给一个类增加多个功能，这样在设计类的时候，优先考虑通过多重继承组合多个`Mixin`的功能，而不是设计多层次的复杂的继承关系
+ Python自带了`TCPServer`和`UDPServer`这两类网络阢，而要同时服务多个用户就必须使用多进程或多线程模型，这两种模型由`ForkingMixin`和`ThreadingMixin`提供。
+ 编写一个多进程模式的TCP服务，一个多线程模式的UDP服务

```python
class MyTCPServer(TCPServer, ForkingMixin):
    pass

class MyUDPServer(UDPServer, ThredingMixin):
    pass
```
+ 一个更先进的协程模型，可以编写一个`CoroutineMixin`

```python
class MyTCPServer(TCPServer, CoroutineMixin):
    pass
```
+ 这样的话，就不需要复杂而庞大的继承链，只要选择组合不同的类的功能，就可以快速构造出所需要的子类
+ 由于Python允许使用多重继承，因此，`Mixin`就是一种常见的设计
+ 只允许单一继承的语言(JAVA)不能使用`Mixin`设计

## 3. 定制类
+ 类似`__slots__`这种形如`__xx__`的变量名或函数名要注意，这些是Python中特殊用途的。
+ `__str__`

```python
class Student(object):
    def __init__(self, name):
        self.name = name
    def __str__(self):
        return self.name

print(Student('mark'))
mark = Student('mark')

# 如果没有__str__方法，那么得到的结果就是一个内存地址，而不是一个字符串
```
+ 在`repl`交互环境中，直接敲`mark`，得到的也是一个地址，因为直接显示变量调用的不是`__str__()`，而是`__repr__()`，两者的区别是`__str__()`返回用户看到的字符串，而`__repr__()`返回程序开发者看到的字符串，也就是说，`__repr__()`是为调试使用的
+ 如果想要直接输出字符串内容，解决办法就是再定义一个`__repr__()`，但是通常`__str__()`和`__repr__()`的代码都是一样的，所以简单来写

```python
class Student(object):
    def __init__(self, name):
        self.name = name
    def __str__(self):
        return self.name
    __repr__ = __str__

print(Student('mark'))
```
+ `__iter__`返回一个迭代对象，然后Python的`for`循环就会不断调用该迭代对象的`__next__()`方法拿到循环的下一个值，直到遇到`StopIteration`错误时退出循环

+ 获取菲波那切数列

```python
class Fib(object):
    def __init__(self):
        self.a, self.b = 0, 1

    def __iter__(self):
        return self

    def __next__(self):
        self.a, self.b = self.b , self.a + self.b
        if self.a > 100000:
            raise StopIteration
        return self.a

f = Fib()
for n in f:
    print(n)
```
+ 按照`Fib()`实例可以使用`for()`循环，看起来和`list`很像，但是把它当做`list`来使用还是不行。
+ `getitem__`按照下标取出元素

```python
class Fib(object):
    def __getitem__(self, item):
        a, b = 1, 1
        for x in range(item):
            a, b = b, a + b
        return a

f = Fib()
print(f[10])
print(f[15])
```
+ 对于`list`，有一个切片方法，在上边的例子中，使用`f[0:5]`会报错，所以需要判断`__getitem__()`传入的参数是否是`int`，或者是一个切片对象`slice`

```python
class Fib(object):
    def __getitem__(self, item):
        if isinstance(item, int):
            a, b = 1, 1
            for x in range(item):
                a, b = b, a + b
                return a

        if isinstance(item, slice):
            start = item.start
            stop = item.stop
            if start is None:
                start = 0
            a, b = 1, 1
            L = []
            for x in range(stop):
                if x >= start:
                    L.append(a)
                a, b = b, a + b
            return L


f = Fib()
print(f[10])
print(f[15])
print(f[0:5])
```
+ 现在这个例子中还有很多工作要做，比如对负数的处理等
+ 如果把对象看成`dict`，`__getitem__()`的参数也可能是一个可以看做`key`的`object`，例如`str`
+ 与之对应的是`__setitem__()`方法，把对象视作`list`或`dict`来对集合赋值。对于还有一个`__delitem__()`方法，用于删除某个元素

+ `__getattr__()`动态返回一个属性，由于在调用类的方法或属性的时候，如果存在，那么就会报错

```python
class Student(object):
    def __init__(self):
        self.name = 'mark'

    def __getattr__(self, item):
        if item == 'score':
            return 89
        if item == 'age':
            return lambda: 25


s = Student()
print(s.name)
print(s.score)
print(s.age())
```
+ 注意，只有在没有找到属性的时候，才会调用`__getattr__`，如果调用在`__getattr__`中没有设定的属性，那么就会返回`None`。如果要是让`class`只响应特定的几个属性，那么就要按照约定，抛出`AttributeError`错误
+ 这样操作实际上把一个类的所有属性和方法调用全部都动态化处理，不需要任何特殊的处理。
+ 完全动态调用的特性就是可以针对完全动态的情况调用，比如`REST API`
+ 如果要写`sdk`，给每一个url对应的api都写一个方法，那么工作量很大，一旦api改动，sdk也要改

```python
class Chain(object):
    def __init__(self, path=''):
        self._path = path

    def __getattr__(self, path):
        return Chain('%s/%s' % (self._path, path))

    def __str__(self):
        return self._path

    __repr__ = __str__

print(Chain().status)
print(Chain().status.user.timeline.list)
```
+ 如果需要针对一个`GET /users/:user/repos`API进行修改，那么在调用的时候，需要把`:user`替换为实际用户名`Chian().users('mark').repos`

+ `__call__()`
+ 一个对象实例可以有自己的属性和方法，在调用实例方法时，可以使用`instance.method()`来调用，也可以在实例本身上调用
+ 任何类，只要定义一个`__call__()`方法，就可以直接对实例进行调用

```python
class Student(object):

    def __init__(self, name):
        self.name = name

    def __call__(self):
        print('My name is %s' % (self.name))


mark = Student('mark')
mark()
print(callable(mark))
```
+ `__call__()`还可以定义参数，对实例进行直接调用，类似于对一个函数直接调用，所以可以把对象看成函数，把函数看成对象。
+ 如果把对象看成函数，那么函数本身也可以在运行期间动态创建出来，因为类的实例都是运行期创建出来的
+ 但是怎么判断一个变量是对象还是函数呢，就需要判断一个对象是否能够被调用，能被调用的对象就是一个`Callable`对象，比如函数和定义的带有`__call__()`的类实例
+ Python的class允许定义很多定制方法，可以非常方便地生成特定的类

## 4. 枚举类
+ 如果要表示十二个月份，定义12个变量显然是不合适的，而且变量是可以被修改的。
+ 所以使用枚举类型定义一个`class`类型，每一个常量都是`class`的唯一实例，Python提供了`Enum`类来实现这个功能

```python
from enum import Enum

Month = Enum('Month', ('Jan', 'Feb', 'Mar', 'Apr', 'May', 'Jun'))
print(Month.Jan)

for name, member in Month.__members__.items():
    print(name, member, member.value)
```
+ `value`属性时自动赋给成员的`int`常量，默认从`1`开始计数
+ 如果需要更精确的控制枚举类型，可以从`Enum`派生出自定义类

```python
from enum import Enum, unique

Month = Enum('Month', ('Jan', 'Feb', 'Mar', 'Apr', 'May', 'Jun'))

@unique
class Weekday(Enum):
    sun = 0
    Mon = 1
    Tue = 2
    Wed = 3
    Thu = 4
    Fri = 5
    Sat = 6
```
+ `@unique`装饰器可以帮助我们检查保证没有重复值
+ 遍历枚举类型

```python
from enum import Enum, unique

Month = Enum('Month', ('Jan', 'Feb', 'Mar', 'Apr', 'May', 'Jun'))


@unique
class Weekday(Enum):
    sun = 0
    Mon = 1
    Tue = 2
    Wed = 3
    Thu = 4
    Fri = 5
    Sat = 6


print(Weekday.Fri)
print(Weekday['Tue'])
print(Weekday.Mon.value)
print(Weekday(1))

for name,member in Weekday.__members__.items():
    print(name, member, member.value)

```
