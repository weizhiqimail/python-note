## 1. 多线程爬虫

多线程是为了同步完成多项任务，通过提高资源使用效率来提高系统的效率。线程是在统一时间需要完成多项任务的时候实现的。最简单的比喻多线程就像火车的每一节车厢。而进程则是火车，车厢离开火车是无法跑动的，同理火车也可以有多节车厢。多线程是为了提高效率。


## 2. threading模块
`threading`模块时python中专门用来做多线程的模块，`threading`模块中最常用的类是`Thread`

+ 传统的方法

```python
import time


def coding():
    for x in range(3):
        print('正在写代码' , x)
        time.sleep(1)


def drawing():
    for x in range(10, 13):
        print('正在画画' , x)
        time.sleep(1)


def main():
    coding()
    drawing()


if __name__ == '__main__':
    main()
```


+ 采用多线程

```python
# encoding: utf-8

import time
import threading


def coding():
    for x in range(3):
        print('正在写代码', x, threading.current_thread())
        time.sleep(1)


def drawing():
    for x in range(10, 13):
        print('正在画画', x, threading.current_thread())
        time.sleep(1)


def single_thread():
    coding()
    drawing()


def main():
    t1 = threading.Thread(target=coding)
    t2 = threading.Thread(target=drawing)

    t1.start()
    t2.start()

    print('查看线程总数: ', threading.enumerate())


if __name__ == '__main__':
    main()

```

+ 使用类的方式

```python
# encoding: utf-8

import time
import threading


class CodingThread(threading.Thread):
    def run(self):
        for x in range(3):
            print('正在写代码', x, threading.current_thread())
            time.sleep(1)


class DrawingThread(threading.Thread):
    def run(self):
        for x in range(10, 13):
            print('正在画画', x, threading.current_thread())
            time.sleep(1)

    t1 = CodingThread()
    t2 = DrawingThread()

    t1.start()
    t2.start()



if __name__ == '__main__':
    main()

```

+ 多线程共享全局变量
多线程都是在同一个进程中运行的，因此在进程中的全局变量所有线程都是共享的，这就造成了一个问题，因为线程的执行是无序的，可能会造成数据错误，所以可以加锁进行锁定

## 3. Lock模式
### 3.1 不加锁的模式


```python
# encoding: utf-8

import threading

tickets = 0


def getTicket():
    global tickets
    for x in range(1000000):
        tickets += 1
    print('tickets: %d' % tickets)


def main():
    for x in range(20):
        t = threading.Thread(target=getTicket)
        t.start()


if __name__ == '__main__':
    main()

```

#### 3.2 加锁的模式

```python
# encoding: utf-8

import threading

tickets = 0
gLock = threading.Lock()

def getTicket():
    global tickets
    gLock.acquire()
    for x in range(1000000):
        tickets += 1
    gLock.release()
    print('tickets: %d' % tickets)


def main():
    for x in range(20):
        t = threading.Thread(target=getTicket)
        t.start()


if __name__ == '__main__':
    main()
```

#### 3.3 Lock版本生产者和消费者模式
生产者和消费者模式是多线程开发中经常见到的一种模式，生产者线程专门用来生产一些数据，然后存档到一个中间的变量中。消费者再从这个中间的变量取出数据进行消费。但是因为要使用中间变量，中间变量经常是一些全局变量，因此需要使用锁来保证数据完整性。

```python
# encoding: utf-8

import threading
import random
import time

gMoney = 1000
gLock = threading.Lock()
gTimes = 0
gTotalTimes = 10

class Producer(threading.Thread):
    def run(self):
        global gMoney
        global gTimes
        while True:
            money = random.randint(100, 500)
            gLock.acquire()
            if gTimes >= gTotalTimes:
                gLock.release()
                break
            gMoney += money
            print('%s生产了%d元钱，剩余%d元钱' % (threading.current_thread(), money, gMoney))
            gTimes += 1
            gLock.release()
            time.sleep(1)


class Consumer(threading.Thread):
    def run(self):
        global gMoney
        while True:
            money = random.randint(500, 1000)
            gLock.acquire()
            if gMoney >= money:
                gMoney -= money
                print('%s消费了%d元钱，剩余%d元钱' % (threading.current_thread(), money, gMoney))
            else:
                if gTimes >= gTotalTimes:
                    gLock.release()
                    break
                print('%s准备消费%d元钱，剩余%d元钱' % (threading.current_thread(), money, gMoney))
            gLock.release()
            time.sleep(1)


def main():
    for x in range(4):
        t = Consumer(name='消费者线程%d' % x)
        t.start()

    for x in range(3):
        t = Producer(name='生产者线程%d' % x)
        t.start()


if __name__ == '__main__':
    main()

```

## 4. Condition版的生产者与消费者模式

Lock版本的生产者与消费者模式可以正常运行，但是存在不足，在消费者中，总是通过`while True`死循环并且加锁的方法去判断。加锁是一个非常耗费CPU资源的行为，因此这种方式有很大的缺点。

使用threading.Condition来实现，threading.Condition可以在没有数据的时候处于阻塞等待状态，一旦有了合适的数据了，还可以使用notify相关的函数来通知其他处于等待的线程。这样就可以不用做一些上锁和解锁的操作，可以提高程序的性能。

threading.condition类似threading.Lock，可以在修改全局数据的时候进行上锁，也可以在修改完毕后进行上锁。

`acquire`，上锁

`realease`，解锁

`wait`，将当前线程处于等待状态，并且会释放锁。可以被其他线程使用`notify`和`notify_all`函数唤醒，被唤醒后会继续等待上锁，上锁后继续执行下边的代码

`notify`，通知某个正在等待的线程，默认是第一个等待的进程

`notify_all`，通知所有正在等待的线程，`notify`和`notify_all`不会释放锁，并且需要在`release`之前调用

```python
# encoding: utf-8

import threading
import random
import time

gMoney = 1000
gLock = threading.Lock()
gCondition = threading.Condition()
gTimes = 0
gTotalTimes = 10


class Producer(threading.Thread):
    def run(self):
        global gMoney
        global gTimes
        while True:
            money = random.randint(100, 500)
            gLock.acquire()
            if gTimes >= gTotalTimes:
                gCondition.release()
                break
            gMoney += money
            print('%s生产了%d元钱，剩余%d元钱' % (threading.current_thread(), money, gMoney))
            gTimes += 1
            gCondition.notify_all()
            gCondition.release()
            time.sleep(1)


class Consumer(threading.Thread):
    def run(self):
        global gMoney
        while True:
            money = random.randint(500, 1000)
            gCondition.acquire()
            while gMoney <= money:
                if gTimes >= gTotalTimes:
                    return
                gCondition.wait()
            gMoney -= money
            print('%s消费了%d元钱，剩余%d元钱' % (threading.current_thread(), money, gMoney))
            gCondition.release()
            time.sleep(1)


def main():
    for x in range(4):
        t = Consumer(name='消费者线程%d' % x)
        t.start()

    for x in range(3):
        t = Producer(name='生产者线程%d' % x)
        t.start()


if __name__ == '__main__':
    main()

```

## 5. Queue线程安全队列
在线程中，访问一些全局变量，加锁是一个经常的过程，如果想把一些数据存储到某一个队列中，Python中内置了一个线程安全的模块叫做Queue模块。Queue模块提供了同步的，线程安全的队列类，包括FIFO队列Queue，LIFO队列。这些队列都实现了锁原语(可以理解为原子操作，要么不做，要么都做完)，能够在多线程中直接使用，可以使用队列实现线程的同步。
+ 初始化`Queue(maxsize)`，创建一个先进先出的队列
+ `qsize()`，返回队列的大小
+ `empty()`，判断队列是否为空
+ `full()`，判断队列是否满了
+ `get()`，从队列中取最后一个数据
+ `put()`，将一个数据放到队列中
